# Webilang AI Speaking Feedback — Vercel starter

- `index.html` — lesson frontend.
- `api/feedback.js` — server-side AI endpoint.
- Add `OPENAI_API_KEY` in **Vercel → Project → Settings → Environment Variables**.
- Redeploy after adding the secret.
- The frontend calls `/api/feedback`; the API key is never stored in the browser HTML.

For a beginner-friendly Russian walkthrough, open `README_FIRST_RU.txt`.
