WEBILANG + VERCEL + AI — ИНСТРУКЦИЯ ДЛЯ НЕПРОГРАММИСТА

Что лежит в этой папке
========================
index.html
    Ваш готовый урок.

api/feedback.js
    Маленький серверный посредник.
    Именно он обращается к OpenAI и прячет секретный ключ.

vercel.json
    Настройки Vercel.

.env.example
    Только пример имени секретного ключа.
    НАСТОЯЩИЙ КЛЮЧ В ФАЙЛ НЕ ВСТАВЛЯЙТЕ.


ЧАСТЬ 1. Создайте аккаунт GitHub
=================================
1. Откройте github.com
2. Нажмите Sign up.
3. Создайте бесплатный аккаунт.
4. После входа нажмите New repository.
5. Назовите его, например:
       webilang-ai-test
6. Выберите Private, если хотите сначала тестировать закрыто.
7. Нажмите Create repository.


ЧАСТЬ 2. Загрузите эти файлы в GitHub
======================================
1. В открытом репозитории нажмите:
       Add file → Upload files
2. Загрузите СОДЕРЖИМОЕ этой папки:
       index.html
       vercel.json
       .gitignore
       .env.example
       папку api с файлом feedback.js
3. Нажмите:
       Commit changes

Важно:
Настоящий OPENAI_API_KEY в GitHub не загружайте.


ЧАСТЬ 3. Создайте проект Vercel
================================
1. Откройте vercel.com
2. Нажмите Sign Up / Log In.
3. Удобнее выбрать Continue with GitHub.
4. Нажмите:
       Add New → Project
5. Найдите репозиторий:
       webilang-ai-test
6. Нажмите Import.
7. Ничего сложного в настройках менять не нужно.
8. Нажмите Deploy.

Через короткое время Vercel даст адрес примерно:
       https://webilang-ai-test.vercel.app


ЧАСТЬ 4. Добавьте секретный OpenAI API key
===========================================
1. Откройте свой проект в Vercel.
2. Откройте:
       Settings → Environment Variables
3. В поле Name напишите:
       OPENAI_API_KEY
4. В Value вставьте свой настоящий API key.
5. Сохраните переменную.
6. После этого сделайте новый Deploy / Redeploy.

Секрет должен храниться В VERCEL, а не в index.html.


ЧАСТЬ 5. Проверьте
==================
1. Откройте адрес Vercel.
2. Перейдите:
       Speaking
3. Запишите ответ так, чтобы появился transcript.
4. Нажмите:
       ✨ Get AI Feedback
5. Должен появиться AI feedback.

Если появляется сообщение:
       OPENAI_API_KEY is not configured...
значит секрет ещё не добавлен в Vercel или проект не был redeployed.


КАК ЭТО РАБОТАЕТ
=================
Ученик
   ↓
index.html
   ↓
/api/feedback
   ↓
Vercel Function
   ↓
секретный OPENAI_API_KEY
   ↓
OpenAI
   ↓
feedback возвращается ученику


ПОЧЕМУ ЭТО БЕЗОПАСНЕЕ
======================
Ученик может видеть index.html.
Но настоящий API key в index.html отсутствует.

Ключ хранится только в Environment Variables Vercel.


СКОЛЬКО НУЖНО КОДИРОВАТЬ?
==========================
Для первого теста — практически нисколько.
Файлы уже подготовлены.
Вам нужно загрузить их, добавить секрет и нажать Deploy.


ВАЖНО ПЕРЕД ПУБЛИКАЦИЕЙ
========================
Для небольшого теста с несколькими учениками этот вариант подходит.

Перед большим публичным запуском Webilang.com желательно добавить:
- ограничение количества AI-запросов;
- проверку разрешённого сайта (origin);
- защиту от автоматических ботов;
- лимит бюджета OpenAI.

Это можно сделать позже, когда базовая версия заработает.
